## Implemented behavior

The actual STM32 BRINGUP_CAL image now contains INSTALL_BEGIN/CHUNK/VALIDATE/
COMMIT/STATUS/READBACK/ABORT, PLC1 IDs 0x55–0x5b, and advertises installation in
IDENTIFY. `WTK_CAL_INSTALL_SERVICE=OFF` compiles the handler out and removes that
capability. PRODUCT/BRINGUP do not link the serial installer.

`app_cal_capture_service.[ch]` and its shell reuse the existing parser, safety
snapshot, USART1 nonblocking TX, session and shared workspace. Capture and install
ownership exclude each other. A received candidate cannot grant measurement
permissions. Invalid candidates cause zero erase/program operations.
`app_calibration_service.[ch]` and `measurement_calibration_store.[ch]` retain the
existing cooperative A/B writer, adding bound slot/sequence selection, draining
abort, uncommitted readback and exact final CRC checks. No partition/schema/model
or measurement equation changed.

Recovery now checks full usability before choosing a slot. A newer structurally
committed but incomplete/numerically invalid/incompatible record cannot displace
the older usable calibration or cause its erasure. Application-service commits
use blank sequence 1, then active usable sequence + 1, blocking UINT32_MAX.
The generic historical low-level writer remains available to existing callers;
serial provisioning and the embedded wizard use the bound service policy.
`measurement_calibration.c` also rejects zero/negative ADC scale metadata.

`pc_osl_install.py` implements real pyserial installation, status, canonical Flash
readback and a C-backed demonstration. The existing capture/calculation CLIs remain
available. See [commands and wire contract](../../../Firmware/tools/PC_OSL_INSTALL.md).
The installer validates locally, checks device identity/capability/successor,
transfers 96-byte chunks, waits for verified activation and checks exact persisted
bytes. Ambiguous writes are never blindly replayed. Reports preserve timestamps,
device identity, hashes, CRC and the unqualified distinction.

The host-only `pc_cal_capture_bridge.c` adds a bounded NOR adapter, reset/partial
programming injection and a post-reset call to the same
`measurement_cal_process_block` used by PRODUCT. Side-channel fault controls are
test-only, not embedded protocol commands. Acquisition samples and electrical NOR
behavior remain simulated; the embedded parser, calibration service, recovery and
store state machine are the real C implementations.
