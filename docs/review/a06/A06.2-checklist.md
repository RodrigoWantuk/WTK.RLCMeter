# A06.2 migration acceptance checklist

A06.1 provides a host engine and synthetic device only. None of the following real
operations is implemented by its simulator operation IDs.

A06.2a now implements identification/status, bounded capture/result/cancel and the
PC COM adapter in the actual `BRINGUP_CAL` binary. A C-backed serial campaign covers
all 33 keys; physical validation remains pending. See [evidence](A06.2a-report.md).
A06.2b now implements candidate transfer, validation, cooperative W25Q installation,
canonical readback and full-usable-slot recovery in the linked BRINGUP_CAL binary.
[Implementation/test evidence](A06.2b-report.md) distinguishes C-backed synthetic
validation from pending physical gates. PRODUCT gate/wizard migration remains
unimplemented.

- Define a development capability and device identification/version/condition
  response. Existing USART1 PLC1 framing and resource receiver remain reusable;
  resource HELLO/STATUS do not yet advertise OSL provisioning.
- Add safe raw OSL capture for a blank device without unlocking normal measurement.
  Reuse acquisition/session evidence, stable repeats, source/headroom checks,
  charger/residual/relay/range permissions and cancellation. Report actual ADC
  scale/offset provenance; do not fabricate calibration to pass a boot gate.
- Echo and bind hardware/model, exact RREF/frequency/amplitude, standard identity,
  usable paths, observed HG, temperature, capture counters and errors. Reject a
  capture after safety interruption; DUT fixture changes must return toward SAFE.
- Implement bounded candidate transfer, explicit timeout/abort/retry, command/header
  semantics and whole-frame CRC. Reuse existing workspace ownership and external
  Flash arbitration; no new acquisition-critical allocation or ISR programming.
- Fully validate all 33 keys and binary32 coefficients before starting an inactive
  slot transaction. Ordinary PC candidates cannot assert physical QUALIFIED.
- Reuse `app_calibration_service` candidate handling and the existing W25Q A/B store.
  Preserve active calibration through erase/program failure; commit marker last;
  full CRC/condition/readback validation before service activation.
- Bind PC output to expected next sequence. Application-service commits now use sequence 1 on blank media and the fully
  usable active successor otherwise; UINT32_MAX blocks writes. The target is the
  opposite usable slot. Both entry points use this bound policy; the generic
  low-level writer retains historical semantics for legacy callers/tests.
- Return installation status, actual persisted sequence/CRC and canonical readback.
  Existing BRINGUP `lab cal frame` exports the active frame; it is not a PRODUCT
  provisioning acknowledgement or arbitrary physical-slot readback interface.
- Automate reset/timeout at every receiver and store state with the actual embedded
  dispatch; test blank device, existing OSL, two usable slots, corrupt newest slot,
  partial commit, invalid candidate and resource-pack coexistence.
- Verify standalone calibrated measurements after reboot, clearly unqualified until
  bench evidence supports qualification; OPEN/SHORT trim cannot replace absolute LOAD.
  OSL replacement must invalidate stale supplementary-curve bindings without
  removing the ON capability or changing the storage layout.
- Only then remove the embedded full wizard/solver fit path, preserving runtime
  correction, candidate validation, acquisition and the reviewed boot prerequisite.
  Obtain the plan-required boot/provisioning migration review before changing that gate.
- Run the full host ON/OFF Debug/Release, Python, ARM Debug/Release/BRINGUP and size /
  profile matrix; measure receiver cost, net savings, RAM/stack and pending MUST budget.
  Do not deploy the A06.1 linker-probe images.
- REQUIRES_BENCH_VALIDATION: assembled-board GPIO safe boot, charger/residual blocking,
  relay/range behavior, excitation/ADC/DMA timing, clipping/SNR, HG overlap, fixture
  parasitics, reference intervals/temperature, independent R/C/L holdouts, actual
  W25Q power interruption and standalone behavior. No accuracy/CAT claim without evidence.
