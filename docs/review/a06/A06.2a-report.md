## Limits and A06.2b boundary

Real STM32 capture service binaries exist; no assembled-board capture has occurred.
COM client execution on an actual device, physical interlocks, residual sensors,
relay/range waveforms, current/headroom, PWM/ADC skew, DMA timing, temperature and
HG/source stability require bench validation. Serial fixture callbacks mock hardware;
they do not qualify physical safety. ADC provenance remains nominal, not calibrated.
Calibration installation, activation, readback of a PC-written slot, reboot recovery
after installation and standalone PC-provisioned measurement remain unimplemented
on the device. A06.1's installation simulator does not establish those capabilities.

Next smallest task is A06.2b: add bounded candidate BEGIN/CHUNK/VALIDATE/COMMIT/ABORT
and readback to this development profile, using the existing calibration service
and A/B transaction. Bind total length, CRC, hardware/model, all 33 keys, unqualified
flags and expected successor sequence; reject incomplete data before any write.
Own the existing workspace exclusively, reject capture while receiving/installing,
program only inactive slot, commit marker last, verify full readback, then activate.
Return actual persisted sequence/CRC and install state. Allocate its real PLC1 IDs
only after checking coexistence; A06.2a implements none of these operations.
Test interruption/reset at every receive/program/commit state with previous active
record recovery. Remeasure linked size. Keep PRODUCT wizard/gate until the complete
replacement and owner-required migration review are satisfied.
